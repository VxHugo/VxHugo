## Projeto em destaque

### CryptoWatch Pro

Aplicativo Android desenvolvido para monitorar USDT/BRL e USD/BRL em tempo real, calcular o spread entre as cotações e auxiliar na identificação de possíveis oportunidades de compra.

O projeto surgiu como uma forma prática de entender melhor o mercado de stablecoins e aplicar conceitos de desenvolvimento Android, consumo de APIs externas, atualização em background e criação de widgets.

Principais recursos:

- Cotação de USDT/BRL via Binance Spot
- Cotação de USD/BRL via API de câmbio
- Cálculo automático de spread
- Recomendação baseada na diferença entre USDT e dólar
- Widget para tela inicial Android
- Sistema de alertas personalizados
- Interface em dark mode

Repositório: [CryptoWatch Pro](https://github.com/VxHugo/crypto-watch-pro)
